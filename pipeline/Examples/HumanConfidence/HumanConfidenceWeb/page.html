Human Confidence demo

This page shows how likely it is that a person is looking at it. The server's 51Degrees Pipeline asks the cloud from the request alone first. Then your browser runs the 51Degrees browser tests, and the page sends the sealed result back, which the Pipeline redeems. The server only reads HumanConfidence and HumanConfidenceSource, and the License Key stays on the server.

The Resource Key this page runs with does not carry Human Confidence, so the cloud gives it no level and the steps below are not asked. Talk to 51Degrees about adding Human Confidence to your account.
